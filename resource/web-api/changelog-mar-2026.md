# Web API Changelog — March 2026

> Source: https://developer.spotify.com/documentation/web-api/references/changes/march-2026
> Fetched: 2026-04-30

## Overview

This changelog documents modifications to the Spotify Web API released in March 2026.

## Changes to Fields

### Album
- **external_ids** — "[REVERTED] Known external IDs for the album. This field was previously marked as removed in the February 2026 changelog but will continue to be available."

### Track
- **external_ids** — "[REVERTED] Known external IDs for the track. This field was previously marked as removed in the February 2026 changelog but will continue to be available."
